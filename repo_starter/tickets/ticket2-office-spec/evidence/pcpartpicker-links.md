# PCPartPicker links

PCPartPicker does not show prices in tenge. I used it only to check that the parts fit together (socket, memory type, M.2, power). Prices are in budget.csv.
Each link proves: the list of parts for one build is compatible and the estimated power is below the power supply rating.

- accountant: https://pcpartpicker.com/list/zKnKNp (estimated power 197 W)
- sales: https://pcpartpicker.com/list/xsMrw3 (estimated power 216 W)
- web developer: https://pcpartpicker.com/list/CFC9R4 (estimated power 176 W)
- designer: https://pcpartpicker.com/list/sWmJNp (estimated power 361 W)

Parts that are not in the PCPartPicker database under the exact model from budget.csv, so I used the closest one only for the compatibility check:
- Case: Deepcool MATREXX 40 3FS (mATX) instead of the PCCooler C3 B310 in all four lists.
- CPU cooler: MSI MAG CoreFrozr AA13 in all four lists (this is the model I priced).
- Accountant memory: Corsair Vengeance 2x8 GB DDR5-5200 CL40 (plain, not the RGB version).
- Designer graphics card: PNY OC GeForce RTX 5060 8 GB. Power supply: MSI MAG A650BNL (white version).
